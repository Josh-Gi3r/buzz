# Preview Studio scope

The current shipped scope is:

1. a device-local library;
2. agent-authored safe HTTP(S) URL handoff and responsive framing;
3. image, video, and local PDF import/viewing;
4. local comments, slide/time anchors, revision metadata, and decisions; and
5. external image/video generation wiring whose live provider success remains unverified at the pinned baseline.

Static website, deck, and film render/edit paths are **engine demonstrations** seeded by deterministic E2E fixtures. They are not general production create/import workflows.

Relay artifact kinds, collaborative review sync, agent feedback delivery, immutable live-page capture, hosted development servers, native mobile sessions, and independent public distribution remain outside shipped scope.

See the [feature truth matrix](../product/feature-matrix.md) and [Preview Studio product page](../product/preview-studio.md).
