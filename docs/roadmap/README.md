# Proposed roadmap

Nothing in this file is shipped or committed to a delivery date.

The next product decisions suggested by the current evidence are:

1. add safe production creation/import for the existing static-site, deck, and film engines;
2. decide whether live URLs need immutable captures rather than revision metadata alone;
3. design an explicit conversation feedback handoff before attempting shared review sync;
4. validate provider integrations with opt-in, cost-controlled live acceptance runs;
5. enforce renderer/network capabilities independently of descriptive manifest fields;
6. reconcile the local artifact schema before registering any relay event kinds;
7. add collaborative artifact kinds only with admission, storage, delivery, migration,
   conformance, and multi-client behavior in one reviewed protocol change; and
8. establish independent distribution identity and an immutable verified release process.

Draft interaction and protocol ideas live under `docs/design/` and `docs/spec/`. They remain
proposals until the [feature truth matrix](../product/feature-matrix.md) changes with source,
test, and runtime evidence.
