# Buzz documentation

Buzz is a collaboration system first: communities, conversations, projects, workflows, media, and agents share one signed-event workspace. This fork adds Preview Studio to the desktop app without changing the relay protocol at the documented product baseline.

Start with [Product overview](product/overview.md). Status words throughout these docs have precise meanings in the [feature truth matrix](product/feature-matrix.md).
