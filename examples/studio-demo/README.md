# Studio demo (static mock)

A single self-contained HTML file that mocks the Preview Studio
direction — library rail, preview stage, review comments, and decisions —
using `localStorage` only. It is **not** the desktop app and shares no code
or state with it.

```sh
python3 -m http.server 8000
# open http://localhost:8000/examples/studio-demo/
```

Screenshots of this mock must not be presented as the desktop app.
